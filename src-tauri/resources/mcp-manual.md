# Claude とつなぐ（MCP）の使い方

おぼえがきのノートを、**Claude Desktop から読んだり書いたりできる**ように
する手引きです。つなぐと、こんな頼み方ができます。

- 「先週の会議のノートを探して、決まったことをまとめて」
- 「この内容で新しいノートを作って」
- 「今日のノートに、さっきの結論を足しておいて」

パソコンの操作に慣れていなくても進められるように、押す場所から書きます。
**途中で分からなくなったら、その章の「うまくいかないとき」を見てください。**

---

## はじめに知っておきたいこと

### ノートはこのパソコンから出ません

つなぐのは、このパソコンの中だけです。おぼえがきは**インターネットに
ノートを送りません**。Claude Desktop があなたのパソコンの中で
おぼえがきに聞きに行き、その答えを見る、という形です。

ただし、**Claude に渡したノートの中身は、Claude の返事を作るために
使われます**。見せたくないノートがあるときは、この手引きの最後にある
「見せない場所を決める」を先に読んでください。

### MCP とは

「アプリ同士をつなぐ共通の決まりごと」のことです。名前は覚えなくて
かまいません。**おぼえがきには、その決まりごとで話せる小さなプログラムが
最初から入っています**（`oboegaki-mcp`）。自分で用意するものはありません。

### 要るもの

| 要るもの | 備考 |
| --- | --- |
| おぼえがき（このアプリ） | 使っているなら準備済み |
| Claude Desktop | 無料で入れられます。claude.ai からダウンロード |
| 保管フォルダ | いま使っているもので大丈夫 |

---

## 手順 1 — 設定をコピーする

1. おぼえがきのメニューから **「おぼえがき」→「環境設定…」**（`Cmd+,`）を開く
2. 上のタブから **「MCP」** を選ぶ
3. **「設定をコピー」** を押す

ボタンの隣に **「コピーしました」** と出れば成功です（数秒で消えます）。
コピーされたのは、こんな短い文字の並びです（場所はあなたのパソコンの
ものになります）。

```json
{
  "mcpServers": {
    "oboegaki": {
      "command": "/Applications/OboeGaki.app/Contents/MacOS/oboegaki-mcp",
      "args": ["/Users/あなた/Documents/OboeGakiNotes"]
    }
  }
}
```

**自分で打つ必要はありません。** 場所を 1 文字でも間違えるとつながらない
ので、必ずこのボタンを使ってください。

---

## 手順 2 — Claude Desktop に貼る

1. Claude Desktop を開く
2. メニューから **「Claude」→「Settings…」**（設定）を開く
3. 左の **「Developer」**（開発者）を選ぶ
4. **「Edit Config」**（設定を編集）を押す

すると Finder が開き、`claude_desktop_config.json` というファイルが
選ばれた状態になります。このファイルをテキストエディタ（「テキストエディット」
でも、おぼえがき以外のエディタでも構いません）で開いてください。

### ファイルが空っぽ、または `{}` だけのとき

中身をぜんぶ消して、**手順 1 でコピーしたものをそのまま貼り付けて**
保存します。これで終わりです。

### 既に何か書いてあるとき

すでに他のアプリをつないでいる場合です。`"mcpServers": {` の次の行に、
コピーしたものの**内側だけ**を足します。

```json
{
  "mcpServers": {
    "すでにあったもの": { "command": "..." },
    "oboegaki": {
      "command": "/Applications/OboeGaki.app/Contents/MacOS/oboegaki-mcp",
      "args": ["/Users/あなた/Documents/OboeGakiNotes"]
    }
  }
}
```

**コンマ（`,`）の付け忘れに気をつけてください。** 項目と項目の間には
コンマが要り、最後の項目の後ろには要りません。

---

## 手順 3 — Claude Desktop を開き直す

設定は**開き直すまで効きません**。

1. Claude Desktop を終了する（`Cmd+Q`。窓を閉じるだけでは終わりません）
2. もう一度開く

開き直したら、入力欄のあたりにある**道具（ツール）のしるし**を押して、
`oboegaki` が並んでいるか見てください。並んでいればつながっています。

試しに、こう聞いてみてください。

> おぼえがきのノートを 3 つ挙げて

ノートの名前が返ってくれば成功です。

---

## できること

つながると、Claude から次のことができます。**読むだけ**のものと、
**ノートを変える**ものがあります。

### 読む

| できること | 頼み方の例 |
| --- | --- |
| 探す | 「"議事録" を含むノートを探して」 |
| 読む | 「"設計メモ" の中身を見せて」 |
| 一覧 | 「仕事フォルダのノートを挙げて」「タグを一覧して」 |
| つながり | 「このノートに関係するノートは？」 |
| 履歴 | 「このノートの前の版を見せて」 |

### 書く

| できること | 頼み方の例 |
| --- | --- |
| 作る | 「この内容で "打合せ 9/12" を作って」 |
| 足す | 「"宿題" の節に、この 1 行を足して」 |
| 今日のノート | 「今日のノートに、この結論を足して」 |
| 書き換える | 「このノートを書き直して」 |
| 片づける | 「このノートを仕事フォルダへ移して」「ゴミ箱に入れて」 |

### やらないこと（安全のための約束）

- **ゴミ箱を空にしません。** 消したように見えても、ゴミ箱の中に残ります
- **ピン留めしたノートは捨てません。** 捨てたいときは先にピンを外します
- **書き換えは、読んでからでないとできません。** あなたがおぼえがきで
  書いた直後に Claude が古い内容で上書きする、という事故が起きません
- **見せない場所（次の章）には、読みにも書きにも行きません**

おぼえがきを開いたまま Claude に書かせても大丈夫です。書かれた内容は
**すぐ画面に出ます**。あなたがそのノートを編集している最中だったときは、
どちらを残すか聞かれます。

## 見せない場所を決める

人に見せたくないノートがあるときは、**フォルダごと隠せます**。

1. 保管フォルダを Finder で開く（左のサイドバーの「フォルダ」の行を
   **右クリック** →「Finder で開く」）
2. `.mcp-ignore` という名前のファイルを作る
3. 隠したいフォルダの名前を **1 行に 1 つ**書いて保存する

```
プライベート
仕事/評価
```

こう書くと、`プライベート` と `仕事/評価` の中のノートは、Claude から
**探しても出てこず、読むことも書くこともできません**。

なお、ゴミ箱（`.trash`）と雛形（`templates`）は、書かなくても最初から
見えません。

## うまくいかないとき

### 道具に `oboegaki` が出てこない

- Claude Desktop を `Cmd+Q` で**終了してから**開き直しましたか（窓を閉じる
  だけでは足りません）
- 設定ファイルの書き方が壊れていませんか。とくに**コンマ**と**かっこ**です。
  自信がなければ、いったん中身を全部消して、手順 1 のコピーだけを貼って
  保存し、開き直してみてください
- おぼえがきを `/Applications` の外（ダウンロードフォルダなど）から
  動かしていませんか。動かしたら、もう一度「設定をコピー」からやり直します

### 「ノートが見つからない」と言われる

- 保管フォルダを途中で変えていませんか。変えた後は、もう一度
  「設定をコピー」→ 貼り直し → 開き直しが要ります
- 隠したいフォルダを `.mcp-ignore` に入れすぎていませんか

### おぼえがきを閉じていても使えますか

**使えます。** おぼえがきと MCP は別々に動くので、夜中に Claude Desktop
だけを開いていても、ノートを読んだり書いたりできます。

### 書かせたくないときは

`.mcp-ignore` に保管フォルダの中のすべてのフォルダを書く、という方法も
ありますが、手っ取り早いのは**設定ファイルから `"oboegaki"` の行を消して
Claude Desktop を開き直す**ことです。つなぎ直したくなったら、また手順 1
からやり直せます。

---

## この手引きをもう一度出すには

メニューの **「ヘルプ」→「Claude とつなぐ（MCP）の手引きを置く」** を押すと、
そのときの最新の内容でもう一度置かれます（このノートは消えません。別の
ノートとして増えます）。

おぼえがき自体の使い方は、ノート「おぼえがきの使い方」にあります。
