# 見本（読み書きを試すための資料）

要望 2026-09-13。**実機で「開いて・書き出して・目で見る」ため**の資料です。
自動テストは `src/lib/samples.test.ts` と `src-tauri/src/pdf.rs` が、
ここの中身が試せる形のままかを見張っています。

作り直すときは:

```bash
make samples
```

（`scripts/make-samples.mjs` と `scripts/make-sample-pdf.swift` が唯一の
出どころ。バイナリを手で置き換えないでください — 何が入っているか
分からなくなります）

## 書き出しを試す

| ファイル            | 何を試せるか                                                                                                                                                                                                                                                                                                                                                           |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `書き出しの見本.md` | 文字修飾（太字・斜体・打ち消し・マーカー・コード・文字色）／リンクと `[[ノート]]`・別名つき／脚注／見出し 1〜4／箇条書き・番号・やること／表（右寄せ・空セル）／引用／`:::note`・`:::details`／コードブロック（ファイル名つき・言語なし）／数式（インライン・別行）／Mermaid（flowchart・sequence）／画像と大きさ指定／水平線／front matter（`slide-font` など）／タグ |

**使い方**: このノートを保管フォルダに置いて開き、

- 「ファイル」→「エクスポート」→「HTML…」→ ブラウザで開く
- 「ファイル」→「エクスポート」→「Word…」→ Word で開く
- 「ファイル」→「エクスポート」→「PowerPoint…」→ 見出し 2 ごとに 1 枚になる
- 「ファイル」→「エクスポート」→「PDF…」（印刷）

を順に試して、崩れていないか見ます。手順と見どころは
`docs/manual_test.md` の「書き出し」の節にあります。

## 読み込みを試す（`読み込みの見本/`）

| ファイル                | 何を試せるか                                                                                                                              |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `見本.pdf`              | 3 ページ。**1 ページ目は文字だけ**（抜き出しが効く）、**2 ページ目は文字と絵**、**3 ページ目は絵だけ**（読み取り = OCR に回る。ADR-0041） |
| `写真.png` / `写真.jpg` | 絵の取り込み（貼り付け・落として添付）と、**絵の中の字の読み取り**（`OBOEGAKI` / `TEST` が読めます）                                      |
| `図.svg`                | SVG の添付（要望 2026-09-09。Qt 版と違い WebView はそのまま描けます）                                                                     |
| `表.csv`                | ノートに落とすと表になる。引用符の中の読点・「」つきの文・**ふぞろいの行**（列が足りない行）を含みます                                    |
| `見本.pptx`             | PowerPoint の取り込み（題・箇条書き・入れ子・発表者ノート・絵のある枚）                                                                   |
| `見本.docx`             | Word の**書き出しの見比べ用**。⚠ 取り込みは未対応です（「インポート」に Word はありません）                                              |

## 注意

- `見本.docx` は「書き出した Word がこのくらいの見た目になるか」を見るための
  ものです。取り込み（Word → ノート）は実装していません
- 絵の中の字はわざと**点で描いた素朴な字**です（読み取りが効くかを確かめる
  ため。写真らしさは狙っていません）
