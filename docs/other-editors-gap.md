# ほかの Markdown エディタと比べて無いもの

- 作成: 2026-09-06
- 比べた相手: Obsidian / Typora / Bear / iA Writer / Notion / Craft / Joplin /
  Logseq / Zettlr / VS Code（Markdown 拡張）/ Qiita のエディタ
- **根拠の別**: 「覚書に無い」は**この版のコードを実際に見て確かめた**。
  「相手にある」は書き手の知識（2026 年前半まで）で、機能表を引き直しては
  いない。採否を決める段になったら、その 1 件だけ最新を確かめること。

関連: 参照実装との差分は [hitofude-gap.md](hitofude-gap.md)、やると決めた
ものは [TASKS.md](TASKS.md)、条件つきの保留は [IDEAS.md](IDEAS.md)。

---

## 0. 先に — 比べる前に置いておく前提

覚書は「**ローカルの .md がすべて。外へ出さない。IT に強くない人が
使う**」という前提で作ってある（spec §1）。だから「無い」の中には

- **入れれば効くのに無い**もの
- **方針として入れない**と決着済みのもの

が混ざっている。以下はその 2 つを分けて並べる。**数の多さは目的ではない。**

---

## 1. 入れれば効きそうなもの（推し順）

| #   | 無いもの                            | 相手              | なぜ効くか                                                                        | 重さ |
| --- | ----------------------------------- | ----------------- | --------------------------------------------------------------------------------- | ---- |
| 1   | `[[ノート#見出し]]` / `[[…\|別名]]` | Obsidian, Logseq  | 長いノートの**中の一点**を指せる。今は 1 本まるごとしか指せない                   | 中   |
| 2   | 画像の大きさ指定                    | Obsidian, Typora  | 写真を貼ると本文幅いっぱいに出る。**縮められない**                                | 小   |
| 3   | 保管フォルダ全体の置き換え          | Obsidian, VS Code | 名前を変えたときに全ノートを直せる。今はノートの中だけ（`Cmd+F`）                 | 中   |
| 4   | リンク先をその場で見る              | Obsidian, Logseq  | 行き来せずに中身を確かめられる。**[IDEAS.md](IDEAS.md) に記録済み**（開いた仮身） | 大   |
| 5   | PDF で書き出す（1 手で）            | ほぼ全部          | 今は `Cmd+P` → 「PDF として保存」。**できるのに気づかれない**                     | 小   |

補足:

- **1** は wikilink の解析（`extended-inline.ts`）と Cmd+クリックの行き先
  （`activation.ts`）の両方に手が要る。`#見出し` は見出しへ飛ばし、`|別名`
  は表示だけ差し替える。**索引（リンクの向き）にも別名を混ぜない**こと。
- **2** は記法を決める要がある。Obsidian 流の `![](img.png|300)` は
  CommonMark から外れる（ほかのビューアでは `|300` が題名に見える）。
  `<img src="…" width="300">` は生 HTML なので書き出しで無効（`html: false`）。
  **`:::` の仲間で受ける**のが覚書の作法には合う。
- **3** は取り消しが要る。履歴（ADR-0023）があるので戻せるが、
  「何件書き換えたか」を見せてから実行する形にしないと怖い。
- **5** はメニュー項目 1 つ。中身は今の印刷と同じ道でよい。

## 2. 上級者向け・条件が揃えば

| 無いもの                              | 相手                 | 覚書での扱い                                                       |
| ------------------------------------- | -------------------- | ------------------------------------------------------------------ |
| リンクされていない言及                | Obsidian             | バックリンクはある。**題名と同じ語**を探して並べるだけなので中規模 |
| front matter を欄で編集（Properties） | Obsidian 1.4+        | 今は隠すだけ。低リテラシ層には効くが、**隠す方針と噛み合わない**   |
| ノートの手動並べ替え                  | Bear, Craft          | 今は更新順 / 名前順。ピン留めで代用できている                      |
| 目次の自動挿入（TOC）                 | Typora, VS Code      | アウトライン（`Cmd+5`）で代用。本文に埋める需要は薄い              |
| 埋め込み検索（意味で探す）            | Obsidian の一部      | **[IDEAS.md](IDEAS.md) の L-4 に条件つきで記録済み**               |
| 日本語の校正（textlint 相当）         | 専用ツール           | 文体チェック（U-4）はある。辞書を積むと `.app` が太る              |
| DOCX / EPUB 書き出し                  | Typora, Zettlr       | pandoc 前提。**外部依存を増やす**ので方針と要相談                  |
| Zotero・文献管理                      | Zettlr, Obsidian     | 学術向け。この層の用途ではない                                     |
| Git 連携                              | Obsidian(プラグイン) | 履歴（ADR-0023）が同じ目的を果たしている                           |

## 3. 方針として入れないもの（決着済み）

| 無いもの              | 決めた場所                                                                         |
| --------------------- | ---------------------------------------------------------------------------------- |
| クラウド同期          | spec §1.2（フォルダを iCloud 等に置けば OS 任せで足りる）                          |
| 共同編集              | spec §1.2                                                                          |
| Windows / Linux       | spec §1.2（移植可能に保つだけ）                                                    |
| 完全 WYSIWYG          | spec §3.1（B 方式を採用 = T1）                                                     |
| プラグイン / 拡張 API | 外から任意のコードが入る。この層に配れない                                         |
| 公開・共有リンク      | 「外へ出さない」が売り。外に出す道は**押したときだけ**（生成 AI への手渡し）に限る |
| 暗号化                | ファイルは素の .md（T1・G3）                                                       |
| モバイル              | macOS 13+ のデスクトップアプリ                                                     |

## 4. 「無い」と思われがちだが**ある**もの

手引きに書いていないだけで動くもの。**書けば増える機能**なので、
1 と同じくらい費用対効果が高い。

| できること                 | やり方                               | 手引き |
| -------------------------- | ------------------------------------ | ------ |
| 行を上下に動かす           | `Alt+↑` / `Alt+↓`                    | 無い   |
| 行を複製する               | `Shift+Alt+↑` / `Shift+Alt+↓`        | 無い   |
| ノートの中を置換           | `Cmd+F` の「置換」                   | 無い   |
| PDF にする                 | `Cmd+P` →「PDF として保存」          | ある   |
| 使っていない画像を片づける | 「ファイル」→「使っていない添付を…」 | ある   |

**複数カーソルは動かない**（2026-09-06 に実機で確かめた）。`Cmd+Alt+↑/↓`
を押しても選択は 1 つのまま — `EditorState.allowMultipleSelections` を
入れていないため。**入れるなら代償がある**: 複数の選択を描くには
`drawSelection` も要り、そうすると選択の帯が本文の**下**に回るので、
6-4 で濃くしたコードブロックの地が選択を隠してしまう（今は WebKit の
素の描画なので隠れない）。**わざわざ壊す価値は薄い**と見て、無いままに
してある。

## 5. 逆に、ほかのエディタに無くて覚書にあるもの

比較の釣り合いのために。ここを削らない判断材料になる。

- **囲み・折りたたみ・脚注・Mermaid・数式・表・コードの色分けが、
  プラグイン無しで最初から**（Obsidian は多くがプラグインか設定）
- **PowerPoint 書き出し**（テンプレートの配色と書体を borrow する）
- **PDF / PowerPoint の読み込み**（画像だけの PDF は OCR で文字にする）
- **手元の生成 AI に読ませる**（要約・レビュー・関連・質問。**送り先は
  自分の機械の中だけ**）
- **選んだ文字を Claude / Gemini / ChatGPT / Copilot へ手渡す**（押した
  ときだけ・確認つき）
- **版の履歴とゴミ箱が最初から**（Obsidian は同期契約かプラグイン）
- **日本語の書き味**（IME を壊さない・`*` の緩和・文字数と行数）
