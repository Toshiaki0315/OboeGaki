# 手動テストチェックリスト

**人にしかできないもの**だけを置く（spec §10）。
リリース前と、Phase をまたぐ変更のあとに通す。

凡例: `[ ]` 未実施 / `[x]` OK / `[!]` NG / `[-]` 今回は対象外

**機械が確かめられることは機械に任せる。** 自動テストに移した項目は
[auto_covered.md](auto_covered.md) にある——**人はこちらだけを見ればよい**。
増えすぎた項目を全部たどるのは現実的でなく、たどれないチェックリストは
形だけのものになる。

以前は同じ表に `[a]`（自動で担保）の印を混ぜていたが、**161 行まで増えて
人の見るぶんが埋もれた**ので、2026-08-27 にファイルごと分けた。

**NG が 1 つでもあれば、末尾の「記録」に何が起きたかを書く。**
チェック欄は目印にすぎず、後から読んで分かるのは記録のほうだけ。
NG は直す前に回帰テストを書く（CLAUDE.md §1）。

## 4. データを失わないこと

このアプリで最も避けたい事故。

**復元ダイアログは「めったに出ないのが正常」。** 実測した時間の流れ:
