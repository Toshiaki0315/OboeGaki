# TASKS.md — 実装タスクと進捗

hitofude（参照実装）との機能差分 [docs/hitofude-gap.md](hitofude-gap.md) を
優先順に並べ直したバックログ（2026-09-03 起票）。各タスクの根拠
（参照実装のモジュール・ADR・タスク番号）は差分一覧の該当行を参照。

優先順の考え方:

1. **第 1 群** — 毎日の利用で穴になっているもの。小さく作れて効きが大きい
2. **第 2 群** — 書き味と表示の完成度。エディタとしての質を参照実装に揃える
3. **第 3 群** — ノート管理・検索・設定の充実。数が増えてから効いてくる
4. **第 4 群** — 大物・専門機能。単体で設計判断（ADR）が要るもの
5. **待ち** — 外部要因でブロック中

着手の規約: 1 タスク = 1 ブランチ、TDD（RED→GREEN→`make check`→commit）。
着手したらチェックボックスを `[-]`（作業中）にし、完了で `[x]` に変える。

## 第 1 群 — 日常利用の穴（最優先）

- [x] **1-1. 前回の vault を記憶して次回起動で自動的に開く**（Q-6）
      保存先はフロント側の設定置き場（localStorage か tauri-plugin-store）。
      開けなかったら黙ってフォルダ選択に落ちる（Q-6 と同じ挙動）
- [x] **1-2. 画像の貼り付け / ドロップ取り込み**（A-2, editor/attachments.py）
      クリップボード画像・ドロップされたファイルを `attachments/` へ保存して
      カーソル位置に `![]()` を挿入。ファイル名は日時 + 一意化
- [x] **1-3. ゴミ箱の後始末**（§7.6, purge_trash / note_actions）
      30 日で自動掃除（vault を開いたときに実行）+「完全に削除」+「ゴミ箱を空にする」。日数は定数で開始し、環境設定（3-9）で可変に
- [x] **1-4. オートペア + URL 貼り付けリンク化**（§5.5-4/5）
      選択して `*` `[` `(` `"` で囲む。URL を選択の上に貼ると
      `[選択](URL)` にする。IME 中のガードと手動チェック追記を忘れない
- [x] **1-5. 文字サイズ変更（Cmd+= / Cmd+-）**（§5.2）
      本文フォントサイズの増減と記憶。永続化は 1-1 と同じ置き場
