# ADR-0065: 見たままモード — 書き込んでいる行だけ記法を出す

- 状態: 採用
- 日付: 2026-09-15
- 関連: spec §6.4（リビール）、ADR-0034（CM6 でのリビールの実現）、B-1（書式ツールバー）

## 背景

見え方はこれまで 2 つだった。**ライブプレビュー**（カーソルの行だけ記法が
現れる = §6.4 のリビール）と、**ソースモード**（`Cmd+/`。全部の記法を出す）。

要望（2026-09-15）: 「カーソル行も記法が出ないモードが欲しい。直しは
メニューバーの絵（書式ツールバー）から行う。**新しく書き込んでいる行**だけは
記法が見えてよい」。読み返しながら手を入れるとき、カーソルを置くたびに
行が横へ動く（記法が現れる）のが目に入って邪魔、という話。

## 決定

第 3 の見え方「**見たままモード**」を足す。

- **カーソルを置いただけ・選んだだけでは記法を出さない。** 太字は太字の
  まま、見出しは見出しのまま、絵は絵のまま
- **書き込んでいる行だけ出す。** 打つ・消す・貼る（CM6 の userEvent で
  `input` / `delete`）が起きた行を「書き込んでいる行」とし、その行だけ
  §6.4 の規則で現す。別の行へ移ると忘れる（また隠れる）
- 書式ツールバーからの書き換え（太字にする・見出しにする）は userEvent を
  持たないので、書き込んでいる行にならない — **記法を出さずに直せる**。
  これがこのモードの主な直し方
- **ソースモードとは排他。** 片方を入れると他方が切れる（全部見せる／
  なるべく見せない、の両立はない）。フォーカス・タイプライタとは独立
- 入口はメニュー「表示 → 書くときの見え方 → 見たままモード」
  （`Cmd+Shift+/`）と歯車。✓ が付く（`menu_checks`）。ソースモードと同じく
  **ノートを跨いで続き、アプリを閉じると忘れる**

## 実現

- `wysiwygField`（ON/OFF）と `typingLineField`（書き込んでいる行の行頭）を
  live-preview.ts に置く。リビールの判定は全部 `touchesSelection` を通る
  ので、そこで「見たままモードなら書き込んでいる行の外は現さない」を挟む
  — 19 か所の呼び手を触らずに、インライン・ブロック・表・絵にまとめて効く
- 装飾を作り直す合図（`revealModeChanged`）に、モードの切り替えと
  「書き込んでいる行」の移り変わりを足す
- 排他は field の update で持つ（view を組まずに試せる）

## 却下した案

| 案                                             | 問題                                                                    |
| ---------------------------------------------- | ----------------------------------------------------------------------- |
| 記法を一切出さない（書いている行も隠す）       | `**` を打っても見えず、閉じ忘れに気付けない。Typora も入力中は見せる    |
| 「新規の行」= 空行から書き始めた行だけ         | 既存の行に書き足すときも記法が要る。「書いたら出る」のほうが説明が短い |
| 選択があるときは現す（§6.4 のコピー前の規則）  | 見たままが目的なので、選んだだけで動くのは邪魔。コピーは見たまま写る    |
| ソースモードと同時に入れられるようにする       | 全部見せる／なるべく見せない、が同時に立つ意味がない                    |

## 影響

- spec §6.4 の表に 1 行足した（全マーカー: 見たままモード ON のときは
  書き込んでいる行だけ現す）
- 手動チェックは docs/manual_test.md「見たままモード」
