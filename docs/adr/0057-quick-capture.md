# ADR-0057: どこからでも書き取り（グローバルショートカット）

- 状態: 採用（実装は TASKS 12-6）
- 日付: 2026-09-11

## 背景

思いついたことを書き留めるまでの動作が長い（アプリを前に出す → 今日の
ノート → 末尾へ）。ポメラの検討（docs/pomera-ideas.md）にある「すぐ書ける」
はここで効く。

## 決定

- `tauri-plugin-global-shortcut` で既定 `Cmd+Shift+Space`（環境設定で変更可・
  無効化可）。押すと**小さな窓**（1 枚、常に前面、本文だけの CM6）が出る
- 書いて `Cmd+Enter` で**今日のノートの末尾に追記**して閉じる（見出し無し、
  時刻の行 `- 14:05 …` は付けない。書いた通りに入る）。`Esc` で捨てる
  （捨てる前に 1 行以上あれば確認）
- 追記はファイルへ書き、主窓が開いていれば外部変更の流れで届く（今日の
  ノートを開いて編集中なら 3 択になる — 稀。書き取りの窓は主窓の編集中は
  「主窓へ送る」= キャレット位置へ差し込むに切り替える）
- 主窓を出さずに使える（アプリがメニューバーに居るだけで動く）。ただし
  アプリが起きていない状態では出ない（常駐エージェントは作らない）

## 根拠

| 案  | 内容                                   | 問題                                                   |
| --- | -------------------------------------- | ------------------------------------------------------ |
| A   | 主窓を前に出すだけのショートカット     | 今日のノートを開いて末尾へ、が残る                     |
| B   | **小さな窓に書いて今日のノートへ追記** | 窓が 2 つになる（設定・状態の共有に注意）              |
| C   | メニューバー常駐アプリ                 | 別プロセス・別配布。ADR-0051 の MCP と同じ理由で見送り |

B。

## 影響

- Tauri の窓が 2 枚になる。`capabilities` に窓を足す。設定と保管フォルダの
  情報は Rust 側の状態（WatchState）から取る
- IME 手動チェック（T5）を書き取りの窓でも通す
