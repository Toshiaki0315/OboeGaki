# ADR-0064: 別名つきノートリンク `[[名前|表示]]` を受ける

- 状態: 採用（2026-09-13。ユーザーの指示）
- 関連: ADR-0011（ノートリンク）、ADR-0053（改名でリンクを書き換える）、
  CLAUDE.md T4（参照実装をオラクルにする）

## 背景

`[[覚書の使い方]]` から飛べるか、という問い（2026-09-13）。素の形は既に
`Cmd+クリック` で飛べたが、**別名つき `[[名前|表示]]` は飛べなかった**。

調べると、3 つの層で扱いがねじれていた。

| 層                                    | 別名つき                          |
| ------------------------------------- | --------------------------------- |
| エディタの解析（`extended-inline.ts`）| **拾わない**（リンクにならない）  |
| 索引・バックリンク（`wikilink::links_in`）| **拾わない**                  |
| 改名の書き換え（`wikilink::rewrite_wikilinks`、ADR-0053）| **拾う**   |

つまり「改名すると書き換わるのに、backlinks には出ず、Cmd+クリックでも
飛べない」。書き換えだけが先に進んでいた。

## 決定

**縦棒の前を名前として扱う。** 3 つの層を揃える。

- 解析: 名前の終わりは `]]` か**最初の `|`**。`[` は名前に入らない（今までどおり）。
  名前が空（`[[|表示]]`）は拾わない — 指す先が無い
- `Cmd+クリック`: 名前の側でも**表示の側でも**同じノートへ行く
- 索引: 名前を `links` 表に入れる（backlinks・図・関連が効く）
- ライブプレビュー: `名前|` の部分もマーカー扱いにして隠す。**読むときは
  表示の字だけ**が見える。カーソルを行に置けば生の字が出る（§6.4 のリビール）
- 補完: `|` を打った後は候補を出さない（今までどおり）。表示の字は名前ではない

## 参照実装との差（T4 の例外）

hitofude の `core/inline_scanner.py` は別名を**拾わない**。オラクル
（`spikes/01-flanking/oracle.json`）にも
`"[[名前|別名]] は未対応なので拾わない"` という行がある。**この 1 件だけ、
意図して違える。**

オラクルの JSON は参照実装から生成した資産なので**書き換えない**。代わりに
`inline-oracle.test.ts` に「意図して違えるもの」の表を置き、**こちらの
期待する形を書いて突き合わせる**（黙って飛ばさない）。差分を持っていることを
テストが覚えている状態にしておく。

## 却下した案

| 案                                          | 問題                                                                   |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| 参照実装に合わせて `rewrite_wikilinks` から別名を外す | 改名でリンクが切れる。**直す方向が逆**                      |
| 別名を拾うが索引には入れない                | Cmd+クリックで飛べるのに backlinks に出ない。ねじれが残る              |
| `名前|` を隠さない                          | 読むときに `会議メモ|前回のまとめ` と出る。別名を書く意味が無くなる    |

## 影響

- `[[名前|表示]]` を書いた既存のノートは、次に索引を作り直したときから
  backlinks に出る（索引は捨ててよいキャッシュ = T7。作り直しは自動）
- 埋め込み `![[名前]]` は別名を受けない（そのままにした。埋め込みは中身を
  出すので、表示の字を別に付ける意味が薄い）
