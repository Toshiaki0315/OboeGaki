# ADR-0045: PowerPoint のデザインテーマをどう当てるか

- **日付**: 2026-09-05
- **状態**: 提案（未採用）。TASKS 5-6 の調査
- **決めること**: 会社のテンプレート（`.pptx`）の見た目に、書き出したスライドを
  どこまで合わせるか

## 背景

書き出しの中身は 5-1〜5-5 で整った（装飾・表・体裁・段組み・色と書体）。
残るのは「**組織のテンプレートに合わせたい**」という要望で、md2pptx の
中心にある機能でもある（あちらは python-pptx でテンプレートを開き、その
レイアウトのプレースホルダに流し込む）。

## 調べたこと（実測 2026-09-05）

書き出した `.pptx` を解いて中を見た。

1. **こちらのスライドはプレースホルダを使っていない。** 位置を決めた
   テキストボックスを置いている（`<p:ph>` はページ番号のフィールドだけ）。
   テンプレートの見た目は **レイアウトのプレースホルダ**が持っているので、
   マスタを差し替えても**こちらの文字には効かない**
2. **色は生の値で書いていた**（`<a:srgbClr val="0A84FF"/>`）
3. **書体を指定しない文字には `typeface` が付かない**（実測）。つまり
   テーマの本文書体がそのまま効く
4. **pptxgenjs は配色をテーマ参照で書ける。** `color: "accent1"` を渡すと
   `<a:schemeClr val="accent1"/>` が出る（実測）
5. **`pptx.theme` は書体だけ**（`headFontFace` / `bodyFontFace`）。配色を
   入れる口は無い
6. テーマの中身は `ppt/theme/theme1.xml` の `<a:clrScheme>`（dk1/lt1/dk2/
   lt2/accent1〜6/hlink）と `<a:fontScheme>`（majorFont / minorFont。
   和文は `<a:font script="Jpan">`）に、素直に入っている

## 選択肢

### A. テーマ参照で組み、テーマだけ差し替える

- こちらの図形の色を `accent1` / `tx1` / `bg1` などの**参照**にする
- 書体は指定しない（テーマの本文書体が効く）
- 書き出したあとの zip の `theme1.xml` の `<a:clrScheme>` と
  `<a:fontScheme>` を、**選んだテンプレートから読んだもので置き換える**
  （取り込みで使っている jszip がそのまま使える）

得るもの: テンプレートの配色と書体。PowerPoint の「デザイン」タブで
あとからテーマを変えても、こちらの色が追従する（参照だから）。
得られないもの: 背景の飾り・ロゴ・レイアウトの寸法。

### B. テンプレートに流し込む（md2pptx と同じ形）

テンプレートの zip を土台にして、その `slideLayout` を参照するスライド
XML を自前で組み、プレースホルダ（`title` / `body`）に文字を入れる。
`presentation.xml`・`[Content_Types].xml`・rels の張り直しも自前。

得るもの: テンプレートの見た目そのもの。
代償: **pptxgenjs を使えなくなる**（土台が違う）。表・コード・画像・箱は
結局こちらで置くことになり、プレースホルダの種類はテンプレートごとに
違う。数日仕事で、テンプレートごとの壊れ方を抱える。

### C. pptxgenjs の出力にマスタとレイアウトを移植

A と B の中間。**両方の悪いところが出る**: こちらの図形は位置が固定なので
レイアウトは効かず、色は生の値のままなので配色も効かない。rels の張り直し
だけが増える。採らない。

### D. 組み込みのテーマを数種類持つ

外部ファイルを読まず、配色と書体の組を 3〜5 個持って front matter で選ぶ。
安上がりで壊れないが、「会社のテンプレートに合わせる」には届かない。

## 提案

**A を採る。** 5-5 で入れた `slide-accent` などの仕組みをテーマ参照へ寄せ、
テンプレートの読み取りを足す（`slide-template: 会社.pptx` のような指定）。
B は「背景の飾りとロゴまで含めて合わせたい」が要件に上がってから、
別の ADR で判断する。

## 根拠

- A は**いま持っている道具だけ**で済む（pptxgenjs + jszip）。テンプレート
  ごとの壊れ方を抱えない
- 4 の実測で、テーマ参照は素直に出ることが分かっている。**あとから
  PowerPoint 側でテーマを変えられる**のは、B には無い利点
- B の代償は「pptxgenjs を捨てる」こと。ADR-0039 で選んだ土台を、まだ
  要件がはっきりしないうちに降りるのは早い

## 影響

- 採るなら: `lib/pptx.ts` の色をテーマ参照へ、`lib/slide-theme.ts` に
  テンプレートからの読み取りを足す。書き出しの後段に zip の後処理が入る
- 5-5 で入れた `slide-accent` は残す（テーマを使わない人向け）。
  テンプレートを指定したときはそちらが勝つ、という順序を決める必要がある
