# ADR-0047: 表示名を「覚書」から「おぼえがき」（ひらがな）にする

- **日付**: 2026-09-06
- **状態**: 採用（ユーザーの指示 2026-09-06）
- **関連**: [ADR-0032](0032-rename-to-oboegaki.md)（表示名の半分をこれで上書きする）

## 何を決めたか

画面に出る名前を **「おぼえがき」** にする。ADR-0032 が決めた
「表示名は覚書」だけを差し替え、**ファイル名・フォルダ名・ID 系は
一切触らない**。

| 用途                                  | 名前                      |
| ------------------------------------- | ------------------------- |
| 表示名（メニューバー・窓・警告・About）| **おぼえがき**（変更）    |
| アプリのファイル名（.app / アイコン） | OboeGaki（据え置き）      |
| 保管フォルダの既定名                  | OboeGakiNotes（据え置き） |
| メタデータフォルダ                    | `.OboeGaki`（据え置き）   |
| バンドル ID / 設定の保存先            | `app.oboegaki.editor`（据え置き） |

## なぜ ID 系を触らないか

`.OboeGaki` やバンドル ID を変えると、**既にある保管フォルダの履歴
（ADR-0023 — 作り直せない）と設定が行方不明になる**。表示名は画面の
文字列にすぎないので、引っ越しの要らない側だけを替える。

## どう直したか

散らばっていた直書きを 1 か所に束ねた（`src/lib/app-name.ts` の
`APP_NAME`）。画面側（警告ダイアログ 6 か所・空の画面の見出し）は
そこを見る。束ねられない側は次のとおり:

- `index.html` の `<title>`（HTML なので定数を差せない）
- `src-tauri/tauri.conf.json` の窓の題
- `src-tauri/src/lib.rs` のアプリメニュー（Rust 側）
- `src-tauri/src/vault.rs` の `MANUAL_TITLE`

## 既知の縁

**既に「覚書の使い方.md」を置いた保管フォルダには、それが残る。**
`seed_manual` は空の vault に一度だけ置く作りなので、古い題のノートが
勝手に消えたり二重になったりはしない。ただし「使い方のノートを置き直す」
を選ぶと**新しい題で別に置かれる**（既存のノートは消さない — ADR-0023 の
「消さない」に合わせた挙動をそのまま踏襲する）。古いほうはユーザーが
捨てられる。

サンプル文（`[覚書](https://example.com/a)` などテストの中の文字列）は
アプリ名ではないので触っていない。
