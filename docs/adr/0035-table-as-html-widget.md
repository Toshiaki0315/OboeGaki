# ADR-0035: 表は HTML の table widget で描く

- **日付**: 2026-09-03
- **状態**: 採用
- **覆す対象**: ADR-0003（罫線を paintEvent で描く・BIZ UDGothic・
  キャレットで表単位リビール）と ADR-0017（収まらない表の折り返し描画・
  行単位リビール）の**実現手段**。見せたいもの（罫線・ヘッダ強調・
  セル内折り返し・ソース無傷）は全て引き継ぐ

## 背景

ADR-0003 / 0017 の複雑さ（全角:半角 = 2:1 の等幅フォント探し、桁数計算、
paintEvent での罫線描画、0.5pt 潰し + 先頭 1 文字拡大による高さ予約）は
すべて「`QPlainTextEdit` はソースの 1 行 = 画面の 1 行」という Qt の制約から
来ていた。CM6 の block widget にはこの制約が無い。

## 決定

1. **表ブロック全体を `Decoration.replace` で HTML の `<table>` に置き換える。**
   ソースには一切触れない（T1）。セル内の折り返しは HTML が自然に行うので、
   ADR-0017 の高さ予約・列幅配分・折り返しアルゴリズムは丸ごと不要
2. **リビールは表単位**（ADR-0003 決定 3 に戻す）。キャレット（または選択）が
   表の範囲に触れている間は生のソースを見せる。ADR-0017 の行単位リビールは
   「折り返し描画では他の行を読める形で残したい」という Qt 実装固有の動機
   だったので引き継がない
3. **等幅フォントは使わない。** 桁揃えの必要が無いので本文と同じフォントで組む
4. 区切り行（`:---:`）の左右揃えは HTML の text-align に写す
5. セル内のインライン装飾（ADR-0031）は v1 ではプレーンテキスト。
   後のスライスでセルごとにインライン解析を掛ける

## 根拠

- Lezer の GFM Table 拡張がブロック・セルの正確なオフセットを返すため、
  データ抽出は純関数にでき、ヘッドレスでテストできる
- 表の抽出・整列判定は previewDecorations 内の純関数（tableData）に置き、
  vitest が守る。描画（widget の DOM）は実機で確認する
