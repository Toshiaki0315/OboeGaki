# ADR-0049: App.tsx の状態と処理を hooks に切り出す

- **日付**: 2026-09-07
- **状態**: 採用（TASKS 9-3。ADR-0048 の続き）
- **関連**: [ADR-0048](0048-split-app-into-components.md)（部品化。ここで
  「次は hooks」と決めた）・T2（文書を React state にミラーしない）・
  T3（Rust 側は WebView 非依存）

## 何を決めたか

ADR-0048 で描画を部品に分けたあとも、`src/App.tsx` には 3,443 行が残った。
その大半は**状態と処理**（自動保存・検索・Ollama）で、描画ではない。
これを **カスタム hooks** として `src/hooks/` に切り出す。

| hook           | 持つもの                                                                                                  | App から受けるもの                                                                                  |
| -------------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `useAssistant` | Ollama の状態（動いているか・答え・考え中・関連・質問・材料）と、要約 / レビュー / 質問 / 止める / 降ろす | ペインの開閉・vault・開いているノート・LLM の設定・打ちかけを書き切る手・本文を読む手・知らせの出口 |
| `useSearch`    | 検索語・結果・保存した検索・タグとフォルダの絞り込み・並び順（3 つは排他）                                | vault・一覧・知らせの出口                                                                           |
| `useNoteSync`  | 自動保存・退避（H-1）・外部変更の取り込み・競合の 3 択・外部削除・前回の未保存                            | vault・開いているノート・エディタの手（本文を読む / 差し替える）・設定・知らせの出口                |

順番はこの表のとおり — **独立しているものから**。`useNoteSync` は
エディタと最も深く結びついているので最後にし、切ったあとは
docs/manual_test.md の保存・競合の項を実機で通す。

## 約束

- **hook は Tauri を直接呼ばない。** Rust を呼ぶ包みは `src/lib/ipc.ts`
  （イベントの購読も含む）。これで hook のテストは `lib/ipc` を差し替える
  だけで書ける（`@testing-library/react` の `renderHook`）
- **hook は EditorView を持たない**（T2）。本文が要るときは
  `() => string` の手を受け取る。文書の真実は CM6 のまま
- **hook の入出力は値と関数だけ**。App の state setter を渡すのではなく、
  hook が自分の state を返し、App はそれを部品へ流す
- 切り出す前後で挙動を変えない。変えるときは別のコミットで、理由を書く

## 置き場所

`src/hooks/` を足す（CLAUDE.md §5 の「勝手に階層を増やさない」への
回答: この ADR が理由）。部品（`components/`）は描くもの、hooks は
状態と処理、`lib/` は純粋な関数と Rust への包み、と役を分ける。
