# ADR-0056: やること一覧（`- [ ]` の横断表示）

- 状態: 採用（実装は TASKS 12-5）
- 日付: 2026-09-11

## 背景

チェックボックス（`- [ ]`）は行の装飾と、押して切り替えるところまで。どの
ノートに未完了のやることが残っているかは、開いて探すしかない。

## 決定

- 索引に `tasks` 表（path・行番号・本文・完了か・期限）を持ち、`index_one`
  で本文から拾う（`- [ ]` / `- [x]`。入れ子も 1 件ずつ）。期限は行の中の
  `@2026-09-30` か `📅 2026-09-30` の形だけを読む（新しい記法を作らない）
- サイドバーに「やること」の節（フォルダ・タグ・保存した検索と同列。
  `Cmd+1` で一緒に消える）。未完了だけを、期限が近い順 → ノートの更新順で
  出す。押すとそのノートのその行へ飛ぶ（`revealPos`）
- 一覧の上で完了にできる（本文の `[ ]` を `[x]` に書く = 本文の編集。開いて
  いるノートなら editor 経由、そうでなければファイルへ書いて外部変更の流れに
  乗せる）
- 完了したものの表示・期限の無いものの扱い・期限切れの色は設定にしない。
  「未完了を、近い順に」の 1 通りで始める（効かないつまみを出さない）

## 根拠

索引は既に本文を 1 行ずつ読んでいる（tags・links）。tasks を足す走査の
コストは小さく、一覧は検索と同じ速さで出る。

## 影響

- スキーマの世代を 1 つ上げる（`index_db` の migration。索引は捨ててよいので
  作り直しでもよい）
- `SlidePreview` / 書き出しには関係しない
