# ADR-0058: `![[ノート名]]` で別のノートを埋め込んで見せる

- 状態: 採用（実装は TASKS 12-7）
- 日付: 2026-09-11

## 背景

リンク（`[[…]]`）とバックリンク、参照ペイン（別のノートを横に読み専用で
開く）はあるが、別のノートの中身を**本文の中に**見せる手が無い。会議の
定型・用語の説明・チェックリストを 1 箇所に置いて使い回したい。

## 決定

- 記法は `![[ノート名]]`（Obsidian と同じ。`![[ノート名#見出し]]` でその節だけ）。
  行まるごとがこれ 1 つのときだけ描く（画像 = ADR-0004 と同じ規則）
- 描くのは**読み専用の widget**。文書は 1 文字も変えない（T1）。中身は
  `read_note` で引き、参照ペインと同じ描き方（CM6 の読み専用 view）で
  入れ子に描く。入れ子の深さは 1 段まで（埋め込みの中の埋め込みはリンクの
  まま）— 循環と重さを避ける
- 埋め込み元が変わったら描き直す（外部変更のイベントに `path` が乗るので、
  同じパスを埋めている widget だけ描き直す）
- HTML / PDF 書き出しは**中身を展開して埋める**（読む側に元ノートは無い）。
  PowerPoint は展開しない（枚数が読めなくなる。コードのまま）
- 押すと元のノートを開く（参照ペインではなく主窓で）

## 根拠

「1 箇所に書いて使い回す」はリンクでは満たせない（読むたびに飛ぶ）。
widget は画像・表・数式で既に使っている描き方で、T1 と T6 を破らない。

## 影響

- `live-preview.ts` の Image と同列の分岐。`extended-inline` に `![[` を
  足す（`[[` の解決と同じ `wikilink::normalize`）
- 見出し指定の切り出しは純関数（`lib/section.ts`）にしてテストする
