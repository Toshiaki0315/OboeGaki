# ADR-0059: Word（.docx）書き出し

- 状態: 採用（実装は TASKS 12-8）
- 日付: 2026-09-11

## 背景

HTML・PDF・PowerPoint の書き出しはあるが、社内文書として求められることが
多いのは Word。今は HTML を Word で開いて整えるか、PDF で我慢している。

## 決定

- `docx`（npm。pptxgenjs と同じく WebView で組んで base64 を Rust に渡す）で
  見出し・段落・箇条書き（入れ子）・表・コード（等幅・背景）・画像（添付は
  埋め込み）・引用・水平線・脚注を写す。数式は MathML → OMML が要るので
  **画像（PNG）にして置く**、Mermaid も PNG（PowerPoint と同じ経路 `svg-png`）
- 見た目は「既定のまま綺麗」（ADR-0046 の考え方）。Word 側の見出しスタイル
  （Heading 1〜）に**割り当てる**ので、受け取った人が目次やナビゲーションを
  使える。字体は環境設定の本文フォントを使い、無ければ Word の既定に任せる
- front matter の `title` があれば表題に、無ければ H1。作成者は書かない
- 設定タブは**作らない**。文書ごとの差は front matter（`docx-font` など）で、
  必要になったら足す

## 根拠

| 案  | 内容                      | 問題                                                      |
| --- | ------------------------- | --------------------------------------------------------- |
| A   | HTML を .doc として渡す   | Word が「Web レイアウト」で開く。見出しスタイルが付かない |
| B   | **docx ライブラリで組む** | 依存が増える（実測してから同梱を判断）                    |
| C   | pandoc を同梱             | 100MB 超。署名・公証の対象が増える                        |

B。

## 影響

- メニュー「書き出し」に Word を足す。`export_write_binary` は既にある
- `.pptx` と同じく、**出来上がった `.docx` の XML** で確かめるテストを書く
