# ADR-0060: 自動更新

- 状態: 採用（実装は TASKS 12-9。署名・公証の後）
- 日付: 2026-09-11

## 背景

今は `.app` を手で差し替えている。配る段になれば、更新の知らせと差し替えが
無いと古い版が残り続ける。

## 決定

- `tauri-plugin-updater`。更新の情報（`latest.json`）は GitHub Releases に
  置き、署名鍵は Tauri の updater 鍵（`tauri signer`）。**Apple の署名・公証
  （TASKS 0-C）が済んでから**入れる — 未署名の .app は差し替えても Gatekeeper
  で止まる
- 起動時に 1 回だけ確かめ、あれば「新しい版があります（0.6.0）— 更新して
  再起動 / 後で」をステータスの上に出す。勝手には入れない。環境設定で
  「起動時に確かめる」を切れる
- 更新の中身（変更点）は Releases の本文をそのまま出す（日本語で書く）
- 保管フォルダには触らない。索引はスキーマ世代で作り直す（既存の仕組み）

## 根拠

配布の入口が GitHub Releases なら追加の置き場が要らない。手動の差し替えを
続けるより、更新の失敗（半端な .app）が起きにくい。

## 影響

- `make dmg` に `latest.json` と署名の生成を足す（Releases への upload は
  GitHub Actions の release ワークフロー）
- 開発版（`make run`）では確かめない
