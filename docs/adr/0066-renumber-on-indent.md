# ADR-0066: 番号付きリストを字下げしたら番号を振り直す

- 状態: 採用（2026-09-17。ユーザーの要望）
- 関連: spec §5.5-3（Enter の継続では振り直さない）、ADR-0026（番号は隠さない）

## 背景

番号付きの項目を Tab で 1 段深くしても、番号はそのままだった。

```
1. データの可視化から
  2. 意思決定するために
3. 機械学習
```

CommonMark はこれでも正しく描く（入れ子の番号は最初の項目の数字から数える）
が、**画面には原文の番号がそのまま出る**（ADR-0026 で番号は隠さない）ので、
入れ子が「2.」のまま見え、親の続きが「3.」になる。要望（2026-09-17）は
「字下げしたところは 1 から数え、親は続きから」。

## 決定

**Tab / Shift+Tab で字下げを変えたとき、そのリストの番号を上から振り直す。**

- 対象は「空行・リストでない行で切れるまで」の 1 つのリスト（`input-assist.ts`
  `renumberList`）。他のリストは触らない
- 同じ深さの並びを 1 つの組として数える。**入れ子は 1 から、親は続きから**
- **先頭の組は元の番号から始める**（`3.` で始めたリストを `1.` に戻さない。
  開始番号は CommonMark でも意味を持つ）
- `.` と `)` は行ごとに保つ。点の箇条書きが同じ深さに挟まると番号の組はそこで
  切れる（CommonMark でも別のリスト）
- 字下げと番号の書き換えは**同じ transaction** に載せる（1 回の取り消しで戻る）。
  書き換えるのは行頭（字下げ + 番号）だけで、本文とカーソルは動かさない

## 振り直さないもの

- **Enter の継続**は §5.5-3 のまま振り直さない（`1.` の次に `2.` を足すだけ）。
  打つたびに下の行が書き換わると diff が散る。字下げは「構造を変える」操作
  なので、そのときだけ整える
- 直接タイプで番号を直したとき・貼り付け。表示は原文どおり（ADR-0026）

## 却下した案

- **表示だけ数え直す**（原文は触らず、装飾で数字を差し替える）: 見えている数字と
  保存される数字が違うのは、原文が真実（T1）という約束の見せ方として紛らわしい。
  参照実装にも無い
- **リスト全体を常に 1 から**: 開始番号を捨てる。CommonMark の意味を壊す
