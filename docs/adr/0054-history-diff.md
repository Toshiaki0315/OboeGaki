# ADR-0054: 履歴の窓に差分を出す

- 状態: 採用（実装は TASKS 12-2）
- 日付: 2026-09-11

## 背景

履歴の窓（HistoryDialog）は版の一覧と本文を丸ごと見せる。どこが変わったか
は目で探すことになり、「戻すか」を決められない。参照実装にも差分は無い。

## 決定

- 版を選ぶと、**今の本文との差分**を行単位で出す（追加は緑・削除は赤・
  変わらない行は畳んで前後 3 行だけ）。比較の相手は切り替えられる
  （今の本文 ↔ 選んだ版 / 選んだ版 ↔ その 1 つ前）
- 差分は純関数 `lib/diff.ts`（行単位の LCS。Myers まで要らない — ノート
  1 本の行数なら O(nm) で十分。5,000 行 × 5,000 行で 25M 比較は数十 ms）。
  テストは固定の入出力で
- 行の中の変わった箇所は**語単位で強調しない**。日本語は分かち書きが無く
  文字単位になって読めない。行の色分けで止める
- 「この版に戻す」「差分のうち削られた行だけ本文に戻す」は今回はやらない。
  戻すは既存の「版を戻す」のまま

## 根拠

差分表示が無い履歴は「あることは分かるが使えない」機能になっている。行単位
の色分けだけで判断に足り、依存も増えない。

## 影響

- `HistoryDialog` に差分ペインが増える（版の本文と差分をタブで切り替え）
- 版の本文の取得（`historyRead`）は既にあるので Rust は変えない
