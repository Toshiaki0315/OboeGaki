## 0. ポメラとは何か（取り入れるときの前提）

**ネットに繋がらない、アプリも入らない、文章を書くだけの機械。**
「集中できる」の正体は機能ではなく**引き算**にある。だから
「ポメラの機能を全部足す」のは筋が悪い。**引き算の思想は既に覚書と
同じ向き**（ローカルの .md だけ・外へ出さない）なので、**足すべきは
日本語で長文を書く人向けの道具立て**に絞る。

ファイルは素の `.txt`。縦書きも見出しも**表示だけ**で、ファイルには
記号がそのまま残る。これは覚書の T1（ソース文字列が唯一の真実）と
同じ考え方で、参考にしやすい。

## 1. 取り入れると効きそうなもの（推し順）

| #   | ポメラの機能                   | 覚書の今                    | 入れる価値                                                 | 重さ |
| --- | ------------------------------ | --------------------------- | ---------------------------------------------------------- | ---- |
| 1   | アウトラインで**節ごと動かす** | アウトラインは**飛ぶだけ**  | 長い文章の構成を組み替えられる。ポメラの目玉               | 中   |
| 2   | 選んだ語を**辞書で引く**       | 無い                        | macOS の辞書に渡すだけ。**「渡す」メニューに 1 行**        | 小   |
| 3   | 原稿用紙の枚数                 | 文字数と行数は出る          | 日本語の書き手はこちらで測る（400 字詰め ◯枚）             | 小   |
| 4   | 行番号の表示                   | 無い                        | 人と原稿をやり取りするとき「◯行目」で話せる。設定に on/off | 小   |
| 5   | カレンダーから日付のメモ       | 今日のノート（`Cmd+T`）だけ | 昨日・先週の分に**戻れる**。日記に使う人に効く             | 中   |
| 6   | Shift_JIS / CRLF を読む        | UTF-8 / LF のみ             | **ポメラや Windows で書いた .txt がそのまま開ける**        | 中   |

補足:

- **1** が本命。アウトライン（ADR-0022）は既にあるので、そこに
  「この見出しの節を丸ごと上げ下げする」を足す形になる。畳む範囲を出す
  `headingSection`（6-2 で直したもの）がそのまま使える。**本文を書き
  換える操作**なので、取り消し（`Cmd+Z`）が 1 回で戻ることを確かめること。
- **2** は「生成 AI に渡す」「Google で検索」と同じ棚に置ける。macOS には
  辞書の URL（`dict://`）がある。**外へ出ない**（手元の辞書）ので、確認の
  窓も要らない。
- **3** は `stats.ts` に 1 行足すだけ。**単語数は出さない**という既存の
  判断（日本語に語の区切りが無い）はそのまま。
- **6** は取り込みだけでよい（書き出しは UTF-8 / LF のまま）。文字コードの
  当てずっぽうは危ないので、**読めなかったときだけ Shift_JIS で読み直す**
  形が安全。

## 2. 面白いが、この機体では効きにくいもの

| ポメラの機能                 | 判断                                                                                                                               |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 縦書き（シナリオモード）     | **表示だけでも茨**。CM6 で縦書きにすると座標・キャレット・選択が総崩れになる。やるなら**書き出し（PDF / HTML）だけ縦書き**が現実的 |
| QR コードで書き出す          | スマホへ渡す道。Mac には AirDrop とクリップボードがある。用途が薄い                                                                |
| メールで送る（アップロード） | 「押したときだけ外へ出す」の枠には収まるが、macOS の共有メニューで足りる                                                           |
| ATOK 相当の校正              | 仮名遣い・誤用の指摘は**辞書を積む**話。`.app` が太る。文体チェック（U-4）で当面代える                                             |
| キー割り当ての変更           | あると嬉しいが、この層には設定項目が増えるほうが害。ショートカットは表を配るだけにする                                             |
| 親指シフト / US 配列         | OS 側の仕事                                                                                                                        |
| 正規表現検索                 | **既にある**（`Cmd+F` の `.*`）。手引きに書けば済む → 6-6 の続き                                                                   |
| ゴミ箱・自動バックアップ     | **既にある**（ゴミ箱・版の履歴 ADR-0023）                                                                                          |

## 3. ポメラから**学ぶ**もの（機能ではなく作法）

- **開いてすぐ書ける。** ポメラは 5 秒で書き始められる。覚書の起動は
  実測 903ms（[bench.md](bench.md)）で足りているが、**起動直後に
  カーソルが本文にある**ことは守り続ける。
- **ファイルは素のテキスト。** 縦書きも見出しも表示だけで、ファイルには
  記号が残る。覚書の T1 と同じ。**この線を越えない**。
- **機能を足しすぎない。** ポメラの価値は引き算。覚書も「できることの
  数」ではなく「迷わず書けること」で判断する。
