# スパイク #4: 音声・動画の文字起こしと議事録づくり — 結果: **GO（条件つき）**

「音声ファイルや動画ファイルから文字起こしをして、議事録を作れるか」（要望
2026-10-09）の下調べ。ADR-0070 を書く前に、**この Mac の中だけで**（外へ何も
出さずに）実用になる速さと出来かを測った。アプリには組み込んでいない。

## 結果（2026-10-09 実測。macOS 26.7.1 / Apple Silicon）

素材: 21 分の対話の録音（AAC `.m4a`・ステレオ・44.1kHz・40MB。技術の話で
固有名詞・英語の用語が多い）。

| 段 | 手段 | 時間 | 出来 |
|---|---|---|---|
| 文字起こし | macOS 26 の SpeechAnalyzer（SpeechTranscriber・ja_JP・この Mac の中） | **8.8 秒** | 9,108 字。用語はおおむね拾う（下） |
| 議事録 | Ollama gemma3:4b（num_ctx 16384） | 52 秒 | 形は守るが**作り話**をする（下） |
| 議事録 | Ollama gemma3:12b（num_ctx 16384） | 129 秒 | 作り話をせず、流れも細かい |

- 文字起こしは**言語データのダウンロード無し**で動いた（`installedLocales` に `ja_JP`）。
  ただし `AssetInventory.status` は `installed` でなく `supported` を返した — 本実装では
  足りないときの案内（ダウンロードの確認）が要る
- 起こした文は 4,939 トークン（gemma3 の数え方）。**1 時間なら 1.5 万トークン前後**の見込みで、
  16K の窓には収まらない — 区切って要約してまとめる（2 段）か、窓を広げるかを決める

### 文字起こしの出来

- 拾えた: OPC UA（26 回）・ラズベリーパイ・MQTT・PLC・Python・Linux・iOS・COM / DCOM・UDP・X.509
- 外した（同音の取り違え）: 「大王次産業革命」（第四次）・「企画」（規格）・「コム」（COM）・
  「10分あり得る」（十分）・「オブジェクト思考」（指向）・人名らしきもの
- 区切りは 45（20〜40 秒ごと）に `[mm:ss]` が付く。**話者は分かれない**（2 人の対話が混ざる。
  macOS の音声認識に話者の聞き分けは無い）

### 議事録の出来

- gemma3:4b: 「やること」に**話に無い項目を 2 つ作った**。音声認識の誤りを直さず用語として
  載せた。チェックボックスを `\[ ]` と崩した
- gemma3:12b: 「決まったこと・やること」を「なし」とし作らない。用語を直す（OPCUA → OPC UA、
  コム → COM）。ただし「大王次産業革命」は直さず、やることを `- [ ] なし`（空のチェックボックス）
  と書いた
- どちらも `[mm:ss]` を各項目の頭に付けられた

## ADR-0070 で決めること（ここから）

1. **文字起こしの道**: macOS 26 の SpeechAnalyzer だけにする（アプリの対象は macOS 13+ なので、
   26 未満では出さない）か、13〜15 向けに SFSpeechRecognizer（**未検証**。長い録音は区切る
   必要がありそう）も持つか
2. **議事録のモデル**: 設定のモデルのまま（既定 gemma3:4b は作り話をする）か、議事録だけ大きい
   モデルを勧めるか。作り話を抑える後処理（`- [ ] なし` を「なし」に直す等）は要る
3. **長さ**: 区切って 2 段で要約するか、窓を広げるか（1 時間で 1.5 万トークン前後）
4. **形**: 1 枚のノートに議事録 + 全文（`:::details` に畳む）+ `[mm:ss]`。音声ファイルは添付に
   置くか（大きい）
5. 話者の聞き分けは**しない**（できない）と手引きに書く

## 再現

```bash
swift probe.swift                                  # ja_JP が使えるか（何もダウンロードしない）
swift transcribe.swift <音声か動画> <出力.txt>      # [mm:ss] 文 を 1 行ずつ
python3 minutes.py gemma3:12b <出力.txt> <議事録.md> # 手元の Ollama（127.0.0.1:11434）
```

起こした文と議事録は**ここに置かない**（素材の中身を含む）。
